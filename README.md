# oxr1-emc4-transcriptomics-analysis

This repository presents an end-to-end bulk RNA-seq analysis of CRISPR-mediated perturbations of OXR1 (activation) and EMC4 (ablation) in α-synuclein overexpression models of neurodegeneration. 

Using publicly available transcriptomic data, this project performs data cleaning, QC, DE (differential expression) analysis, and pathway enrichment to investigate transcriptomic changes linked to neurodegenerative diseases (NDD), specifically multiple system atrophy (MSA).
